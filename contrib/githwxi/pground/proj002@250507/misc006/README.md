# Eight-Queen Puzzle

## Date

Mon Dec 22 06:02:57 PM EST 2025

## Description

The 8-queen puzzle asks the player to place
8 queen pieces on a check board (of dimension 8 by 8)
such that no queen piece in the placement can attach
any other queen pieces, that is, no two queen pieces
can be on the same row, the same column, or the same
diagnal.

## Implementation

An implementation is given that makes direct use of
breadth-first search. This implementation is adapted
from one that was done in December, 2020, when the first
compiler for ATS3 (written in ATS2/Postiats) was built
that compiles ATS3 to JavaScript).
