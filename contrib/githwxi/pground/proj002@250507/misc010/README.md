## Description

This example builds a stream of English words for
solving a little word puzzle. It tells a good story
as to why filtering on a stream needs to be done in
a tail-recursive manner.

## Implementation

The implementation is adapted from an earlier version that
was done in December, 2020, when the first compiler for ATS3
targeting JavaScript was ready for testing.
