## Description

Doublets is a word game invented by Lewis Carroll (1832-1898), the
author of children's classics "Alice in Wonderland". Please search
the Internet for details.

## Implementation

The implementation is adapted from an earlier version that was done in
December, 2020, when the first compiler for ATS3 targeting JavaScript
was ready for testing. The graph-based breadth-first search
implemented in [ggrph.dats](./ggrph.dats) is an informative example
showcasing the so-called template-based programming as is advocated by
ATS3.
