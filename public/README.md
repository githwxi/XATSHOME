# XATSHOME webpage

A standalone, responsive repository overview. Content is based on the root
README, prelude documentation, and contributor examples in this checkout.

Open `index.html` directly in a browser, or serve this directory from the
repository root:

```sh
python3 -m http.server 8000 --directory public
```

Then visit http://localhost:8000. No build, packages, JavaScript, or external
fonts are required. Repository links point to `githwxi/XATSHOME` on GitHub;
compiler development links point to `githwxi/ATS-Xanadu`.

Files: `index.html` contains the content; `styles.css` contains the layout,
responsive rules, and accessible focus/reduced-motion styles.

`assets/ATS3-logo.png` supplies the header and footer logo and browser favicon.
