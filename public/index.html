Your first steps
with ATS3.

Start with a local checkout and follow the contributor examples. The bundled JavaScript-hosted compilers run with Node.js.

01

Get the repository

git clone https://github.com/githwxi/XATSHOME.git
cd XATSHOME
02

Set your home directory

In bash, from the root of your checkout:

export XATSHOME="$PWD"

Explore the Makefiles for compilation and runtime setup, then create your own directory under contrib/.
